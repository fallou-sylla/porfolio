# Fallou Sylla — Premium Portfolio

Portfolio bilingue français/anglais, style Tesla + IA futuriste.

## Déploiement GitHub Pages

1. Créer un dépôt public `portfolio-fallou`.
2. Envoyer `index.html`, `style.css`, `script.js` et le dossier `assets`.
3. GitHub → Settings → Pages → Deploy from a branch → `main` / `/root`.
4. URL attendue : `https://fallousylla.github.io/portfolio-fallou/`

## À personnaliser

- Ajouter le CV PDF dans `assets/`.
- Remplacer les illustrations CSS par tes vraies photos et vidéos.
- Ajouter les liens GitHub de chaque projet.
